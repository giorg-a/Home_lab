# Old Architecture

This folder contains my original home lab setup and the writeups from building it.

It is kept here on purpose, to show how the lab evolved. The architecture was limited and lacked many things that the newer version fixes, such as a dedicated management interface and a separate WAN side for testing from an external machine.

The writeups still stand on their own and document what I learned along the way. For the current setup, see the `New_architecture` folder.

## Contents

- `Day_1` to `Day_7`: day-by-day lab notes
- `pfsense_firewall`: pfSense firewall setup
- `linux_server_hardening`: Linux server hardening
