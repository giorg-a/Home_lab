# Cybersecurity Home Lab

This repository documents my hands-on cybersecurity home lab, built to
simulate real-world attack and defense scenarios.

The environment includes an attacker machine, monitored endpoints, and
security monitoring tools to study how attacks happen, how they are
detected, and how defenders investigate them.

Focus areas: - Network monitoring and intrusion detection - Endpoint
detection and response (EDR) - Vulnerability scanning - Attacker
behavior analysis - Security alert investigation - Practical
troubleshooting and system configuration

Each lab day explores a different concept through practical testing and
analysis.

This project represents continuous learning through building, breaking,
detecting, and understanding real security workflows.
